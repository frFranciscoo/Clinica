# Clínica da Pele

Proposta inicial de landing page para apresentação ao Dr. Evandro Santos.

## Visualização local

Abra `index.html` diretamente no navegador ou execute um servidor estático na pasta do projeto.

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

Depois, acesse `http://127.0.0.1:4173/`.

## Estrutura

- `index.html`: conteúdo e estrutura semântica da landing page.
- `styles.css`: direção visual editorial, animações e breakpoints responsivos.
- `script.js`: menu mobile, FAQ, cabeçalho e revelações ao rolar.
- `assets/`: fotografias otimizadas em WebP.
- `design-qa.md`: registro da comparação visual e dos testes realizados.

## Conteúdo provisório

- As imagens do médico e do edifício foram preparadas para esta proposta e devem ser substituídas por fotografias oficiais na versão final.
- Convênios e horários são confirmados pelo WhatsApp.
- Os tratamentos foram transcritos das informações publicadas pela Clínica da Pele no Instagram.
